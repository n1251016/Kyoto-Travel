# Kyoto Travel

初めて京都を訪れる人を対象に制作した、架空の京都観光サイトです。

## サイト概要

観光スポットを紹介するだけではなく、モデルコースや移動方法を掲載することで、旅行計画から現地での移動までをサポートすることを目的として制作しました。

「どこへ行けばよいか分からない」「複数のサイトを見比べるのが大変」といった課題を解決できるよう、情報量を整理し、初めて京都を訪れる人でも迷わず利用できるサイトを目指しています。

- 共通CSSとページ固有CSSを分けた管理しやすい構成
